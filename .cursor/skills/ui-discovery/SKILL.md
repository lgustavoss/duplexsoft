# UI Discovery

## Goal
Produce a concise product/UX brief and page-level strategy before implementation. Visual craft playbooks live in Impeccable.

## Procedure
1. Read `PRODUCT.md` (canonical). Use `product-design-brief.md` only as a legacy mirror.
2. Inspect the repository: framework, routing, CSS strategy, tokens (`DESIGN.md` / `globals.css`), assets, screens.
3. Identify primary users, top tasks, density, device context, and constraints.
4. Identify brand commitments worth preserving.
5. If context is insufficient for a consequential decision, ask one focused question; otherwise record assumptions.
6. Define IA, navigation, required states, and conversion path. For visual direction details, recommend `/impeccable shape` or `/impeccable document` rather than inventing a parallel system.
7. Update `PRODUCT.md` (not a competing brief) when product facts change.

## Proportionality
For a small isolated component change, skip full discovery — inspect local context only.

## Guardrails
- Do not select a design trend because it is fashionable.
- Do not invent brand colors, customer data, or product capabilities.
- Do not implement until the design direction is coherent enough for the requested scope.
