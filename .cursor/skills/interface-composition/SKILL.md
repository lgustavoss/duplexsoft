# Interface Composition

## Prefer Impeccable
For hierarchy, spacing, typography, and composition work, prefer:
- `/impeccable shape` (plan before code)
- `/impeccable layout` / `/impeccable typeset` / `/impeccable distill`
- Context from `DESIGN.md` + `PRODUCT.md`

Use this skill only as a thin fallback or to summarize a handoff after Impeccable planning.

## DuplexSoft constraints
- Marketing (Persuade): brand story, proof, conversion — not dashboard conventions.
- Tokens and CTA pair from `DESIGN.md` (brand filled + outline secondary).
- One primary task per view; hierarchy via type/contrast/grouping, not card wrappers.
- Domain copy: postos, DX Web, WebPosto, Triângulo Mineiro.

## Output
Describe layout, hierarchy, key components, states, and responsive behavior briefly, then hand off to `senior-frontend-engineer`.
